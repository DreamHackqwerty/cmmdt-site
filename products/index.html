Fisch macro · macOS & Windows

ALware Fisch Macro

ALware is a free, non-external, color-based macro for Fisch. It watches the colors on your screen to handle the fishing loop, and it runs on both macOS and Windows.

  • Free to use
  • Color-based detection
  • Non-external
  • Works on macOS and Windows

What’s new in Quasar v3.5.0
  • New rods. Lullaby, Halibut Harpoon, Tranquility Rod, Bellona’s Waraxe, Nate’s Blade and DreamBreaker.

Icon customizer

SwitchUp

SwitchUp lets you change the icon of any app on your Mac. Drop in a PNG, pick the app, and apply. Your image is fitted to the macOS icon grid automatically.

  • Drag and drop a PNG and an .app
  • Optional rounded mask and shadow
  • Fits the macOS icon grid
  • Restore the original icon any time

Record & replay

TinyRepeat

TinyRepeat is a native macOS fork of TinyTask, the Windows recorder. Press Rec, do the task once, then play it back as many times as you need.

  • Records mouse and keyboard input
  • One-click playback
  • Save and open recordings
  • Small native Mac window
  • Shares the same files as TinyTask on Windows

Roblox bootstrapper

ALware Manager

ALware Manager is an all-in-one Roblox bootstrapper and account manager for macOS. Launch Roblox, switch accounts and tune the client from one window.

  • Multiple Roblox accounts
  • FastFlags and graphics settings
  • Servers, history and customization
  • One-click Play
