TinyRepeat

TinyRepeat is a native macOS fork of TinyTask, the Windows recorder. Press Rec, do the task once, then play it back as many times as you need.

  • Records mouse and keyboard input
  • One-click playback
  • Save and open recordings
  • Small native Mac window
  • Shares the same files as TinyTask on Windows
