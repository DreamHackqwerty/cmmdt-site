# cmmdt.org

CMMDT's website, served by GitHub Pages at https://cmmdt.org.

| Path | What it is |
|---|---|
| `/` , `/products/…`, `/features`, `/about` | The main site (plain HTML; `style.css`, `site.js`, images in `assets/`) |
| `/portal/` | The ALware Portal (Supabase backend; settings in `portal/config.js`) |
| `CNAME` | The custom domain GitHub Pages serves this repo on |
| `.nojekyll` | Serve the files exactly as they are (no Jekyll processing) |

Every push to `main` is live within a minute or two.
